## 3. لوحة التحكم: من أين يأتي كل رقم

| الإحصائية | المصدر | هل يتأثر بفلتر التاريخ؟ |
|---|---|---|
| إجمالي الشركات / النشطة | `Clients` (حسب صلاحية المستخدم) | لا |
| المكالمات، البريد، الزيارات، الجولات، الاجتماعات | `Activities.ActivityTypeId` | نعم (`ActivityDate`) |
| متابعات اليوم / المتأخرة / القادمة | `FollowUps` المفتوحة، مقارنةً بـ `DueAtUtc` وبيوم مسقط الحالي | لا (الوضع الحالي) |
| المشاريع المحتملة | الحالات من New إلى Negotiation | لا |
| الفوز / الخسارة | `ProjectStatus` + `ClosedDate` | نعم |
| الرسوم البيانية | تجميع (GROUP BY) داخل SQL Server حسب اليوم أو الشهر أو السنة | نعم |

**الصلاحيات:**
- **المدير ومدير المبيعات:** يريان كل البيانات، ويمكنهما الفلترة حسب أي موظف، ويريان رسم «أداء الموظفين».
- **الموظف:** يرى أنشطته ومتابعاته ومشاريعه وشركاته فقط. إذا طلب شركة غير مسندة إليه يُرفض الطلب (HTTP 403)، ولا يستطيع التحايل بإرسال رقم موظف آخر.

## 4. قرارات التصميم

- **الألوان:** ألوان Apple للواجهة والأيقونات. أما ألوان سلاسل الرسوم البيانية فهي لوحة ألوان **مُختبرة** بأداة فحص: ألوان Apple الأصلية لم تجتز اختبار عمى الألوان (الأخضر بجانب البرتقالي) ولا اختبار التباين على الخلفية الفاتحة.
- **كل رسم بياني له زر «عرض كجدول»**، لقراءة الأرقام الدقيقة ولمن يصعب عليه تمييز الألوان.
- **المادة الزجاجية:** `backdrop-filter` للبطاقات والشريط العلوي والقائمة. القوائم المنبثقة شبه مصمتة، لأن طبقة زجاجية داخل طبقة زجاجية أخرى لا تعمل ويصعب قراءتها.
- **احترام إعدادات الجهاز:** تقليل الحركة، تقليل الشفافية، التباين العالي، والطباعة.
- **المظهر** (فاتح / داكن / تلقائي) يُحفظ في المتصفح. **اللغة** تُحفظ في Cookie وفي حساب المستخدم، فتُطبَّق تلقائياً عند الدخول من أي جهاز.
- **العربية:** تقويم ميلادي وأرقام لاتينية، فتبقى التواريخ والمبالغ موحدة في اللغتين.

## 5. DevExtreme

تمت إزالة DevExtreme بالكامل بطلب منك، واستُبدل بجدول بيانات خاص بالنظام (wwwroot/js/grid.js) وبقوائم Tom Select المجانية. راجع [System_Guide.md](System_Guide.md).

## 6. الاختبارات التي أُجريت

1. أرقام لوحة التحكم طابقت الحساب اليدوي من بيانات اختبار مؤقتة: 13 إحصائية للمدير و13 للموظف، والرسوم حسب اليوم والشهر والسنة.
2. الموظف: طلب شركة غير مسندة إليه أعاد 403، والقائمة الجانبية أخفت المستخدمين والإعدادات.
3. التنبيهات: كل مستخدم يرى تنبيهاته فقط. محاولة تعديل تنبيه مستخدم آخر أعادت 404، والطلب بدون رمز CSRF أعاد 400.
4. تبديل اللغة: يعود للصفحة نفسها، ويرفض إعادة التوجيه إلى مواقع خارجية، ويحفظ الاختيار في حساب المستخدم.
5. رسائل التحقق في صفحة الدخول تظهر بالعربية.
6. صور فعلية عبر Chrome: إنجليزي فاتح، عربي داكن، جوال بالعربية مع القائمة الجانبية. لا توجد أخطاء JavaScript ولا ملفات مفقودة.
7. حُذفت بيانات الاختبار، وفحص قاعدة البيانات `--verify-db` ما زال ناجحاً (24/24).
